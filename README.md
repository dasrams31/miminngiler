# MiminNgiler

Brand affiliate: unboxing & review jujur peralatan rumah tangga dan kebutuhan perempuan.

Tagline: *"Mimin aja ngiler, apalagi kamu~"*

## Isi repo

| Folder | Isi |
|---|---|
| `brand/` | Logo PNG/WebP, versi lingkaran, watermark (teks + logo) |
| `cover/` | Sampul Facebook Page (820x312) |
| `intro/` | Bumper intro 3 detik ("Halo guys! MiminNgiler") |
| `videos/` | Template video 23 dtk (intro + konten 20 dtk): versi A ending "Link ada di komentar!" (FB/Threads/YouTube), versi B ending "Komen MAU, cek DM!" (IG/TikTok) |
| `calendar/` | Kalender konten 30 hari (6 Okt – 4 Nov 2026): 30 produk + hook + kelebihan + panduan posting |

## Brand

- Warna: ungu tua `#3D2B6E` + kuning `#FFD93B`
- Voiceover: Bahasa Indonesia santai, suara perempuan
- Format video: vertikal 1080x1920, 23 detik

## Strategi distribusi

- FB Page / Threads / YouTube: link affiliate di komentar (bisa diklik)
- Instagram: komen "MAU" → kirim link via DM; link utama di bio
- TikTok: keranjang kuning (TikTok Shop Affiliate)
